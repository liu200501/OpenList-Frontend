## 二、功能详情（前端）

### 1. 存储页驱动分类：大字号 + 可折叠 + 折叠持久化

[src/pages/manage/storages/Storages.tsx](../../src/pages/manage/storages/Storages.tsx)

- 把 `beat1` 里网格分组的简单 `Heading` 抽成 `DriverGroup` 组件：标题升级为 `size="lg"`，整行可点击折叠/展开，折叠箭头带 150ms 旋转过渡，旁边 `Badge` 显示该组数量；
- 折叠状态用 `@solid-primitives/storage` 的 `createStorageSignal` 存到 `localStorage`，key 为 `storages-collapsed-drivers`，按驱动名记录哪些组被折叠；
- **关键修复**：signal 提到模块级单例（所有分组共享），并提供 `serializer: JSON.stringify` / `deserializer: JSON.parse`（带容错回退 `[]`）。不提供序列化时该库会把数组存成 `"A,B"` 字符串、读回也是字符串，导致函数式 setter 与 `includes` 全部失效——这正是最初「持久化没成功」的根因。

### 2. crypt 存储隐藏明密文对照入口

[src/pages/manage/storages/Storage.tsx](../../src/pages/manage/storages/Storage.tsx)

- 新增 `nameMapEnabled` memo：解析 `props.storage.addition`，当 `name_map_scan === false` 时返回 false；解析失败或字段缺省时按 `true` 处理（兼容老配置）；
- 把「明文 / 密文对照」按钮的显示条件由 `driver === "Crypt"` 改为 `nameMapEnabled()`——`name_map_scan` 关闭时不会建立完整对照索引，入口无数据，直接隐藏。

### 3. 索引监听规则表格化编辑器

- 新增 [src/pages/manage/settings/IndexWatchRules.tsx](../../src/pages/manage/settings/IndexWatchRules.tsx)：一条规则一行，字段 `enabled`（下拉：是/否）、`driver`（下拉，空表示不限）、`path`、`interval`、`depth` 各自独立输入；支持新增/删除行；对外仍以 `JSON.stringify` 序列化成后端期望的 JSON 数组，解析带容错；
- [src/pages/manage/settings/SettingItem.tsx](../../src/pages/manage/settings/SettingItem.tsx)：当 `props.key === "index_watch_rules"` 时渲染该编辑器，并抑制重复的 helper text（编辑器内部已自带 tips）；
- 新增 `settings.index_watch_rules_fields.*` 中英文案（`enabled`/`driver`/`path`/`interval`/`depth`/`any_driver`）。

### 4. 右键收藏：二级收藏夹菜单

[src/pages/home/folder/context-menu.tsx](../../src/pages/home/folder/context-menu.tsx)、[src/pages/home/folder/collect.ts](../../src/pages/home/folder/collect.ts)、[src/store/favorite.ts](../../src/store/favorite.ts)、[src/utils/api.ts](../../src/utils/api.ts)

遵循「「收藏到…」一个入口，单击进根目录，展开进二级夹」的最终形态：

- 把原先的收藏 `Item` 改成一个 `<Submenu label="收藏到…">`：
  - **单击 label**：`e.stopPropagation()` 阻止 Submenu 自身开合（子菜单靠 hover 展开），调用 `toggleCollect()` → `toggleObjFavorite()` 收藏/取消到**根目录 `/收藏`**，支持多选；
  - **hover 展开**：列出二级收藏夹，每项点击调用 `collectToFolder(dir, obj, folder.mountPath)` 收藏/取消到该夹；
  - label 上的星标反映根目录收藏状态（实心亮色 = 已收藏，空心灰 = 未收藏）；
- 二级收藏夹数据源来自后端新接口 `GET /admin/storage/collect/folders`（即 `/收藏` 的 `fine_favorites` 配置）：
  - **严格按配置行顺序**；只列收藏夹，不含根目录 `/收藏`，不含目录里的文件；
  - 列表做 5 秒节流，避免每次列目录都多一次请求；并行拉取每个子夹的已有收藏，用于正确标记「✓ 已收藏到该夹」；
- 新增 `collectToFolder()`：状态判断放在 API 调用**之前**锁定（否则本地集合更新后会得到相反结果），成功后同步 `folderFavoritePaths`；
- `favorite.ts` 新增 `folderFavoritePaths` / `isPathInFolder` / `setPathInFolder` / `refreshFavoriteFolders` 等，导出 `favoriteFolders`；
- 新增 `home.toolbar.collect_to` 中英文案（「收藏到...」/ "Add to folder..."）。

### 5. 纯图片压缩包无缝秒开

[src/pages/home/previews/archive.tsx](../../src/pages/home/previews/archive.tsx)、[src/pages/home/folder/GridItem.tsx](../../src/pages/home/folder/GridItem.tsx)

- `GridItem` 的 `itemHref()` 给 `ObjType.ARCHIVE` 追加 `?preview=archive`，保证压缩包固定进预览页而不被「下载优先」等设置带去下载页；
- archive 预览新增 `onlyImages` memo（有文件且**全部**为图片，不能用 `imageFiles().length > 0`，否则混排包会误判）；
- 一次性 `createEffect`：文件列表到达且无密码/无错误时，自动 `changeFile(files()[0].name)` 打开第一张图——不跳路由、不显示 loading，直接在当前组件切换，做到无缝；用 `hasAutoOpened` 保证只触发一次，用户点面包屑回列表后不再被强行拉回；
- 网格视图显示条件由 `imageFiles().length > 0` 改为 `onlyImages()`。

### 6. 右键「移动」默认定位当前路径

[src/pages/home/toolbar/CopyMove.tsx](../../src/pages/home/toolbar/CopyMove.tsx)

- 给 `Move` 的 `ModalFolderChoose` 传 `defaultValue={() => pathname()}`。该组件与文件夹树的 `autoOpen` + `createMatcher` 配合，会自动展开到当前路径并选中，不再从全局根 `/` 开始。（`Copy` 保持原样，未改动。）

## 三、后端配套改动（简述）

配套后端仓库 OpenList 本轮同步改动，供前端功能依赖：

- 新增 `GET /admin/storage/collect/folders`（`server/handles/fine_favorite.go` + `server/router.go`）：解析 `/收藏` 别名存储的 `fine_favorites`，按配置行顺序返回 `{name, mount_path}`，不含根目录与文件；
- `internal/bootstrap/data/setting.go`：`image_preload_count` 默认值 `2` → `10`；
- `internal/op/extract_cache.go`：压缩包提取缓存 TTL 30 分钟、上限 2GB；
- `server/handles/archive.go`：压缩包预览响应加 `Cache-Control: public, max-age=1800`。

## 六、备注

- 折叠持久化使用 JSON 序列化是必须项：底层 `createStorageSignal` 默认用 `value + ""` 存储，数组会被压成逗号串无法还原；老的错误数据（如 `"A,B"`）在 `deserializer` 中会 `JSON.parse` 失败并安全回退到 `[]`，不影响使用；
- 右键收藏经过多轮校正后的最终形态是**单一「收藏到…」入口**：单击进根目录、展开进二级夹，不再有独立的「收藏」项；
- 本报告与后端仓库 `更新报告/4.2.9.10.me.beat1.md` 配套阅读，二者共同构成本轮改动的完整记录。
