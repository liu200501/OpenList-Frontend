## 二、议题详情（前端）

### 1. 驱动筛选只列已挂载驱动

[src/pages/manage/storages/Storages.tsx](../../src/pages/manage/storages/Storages.tsx) 原先调用 `/admin/driver/names` 拉取后端支持的**全部**驱动，无论是否已挂载。改为：

- 从已加载的存储列表 `storages()` 派生 `mountedDrivers`，去重后按本地化名称排序；
- 删除 `/admin/driver/names` 请求与 `drivers` signal、`Resp` 类型引用；
- 用 `createEffect` 在存储列表变化时清理已失效的选中项（例如用户删掉某驱动的最后一个存储）；
- 只在 `mountedDrivers().length > 0` 时显示筛选下拉。

### 2. 表格「驱动」列排序

- 新增 `driverSort` 状态（`none` / `asc` / `desc`），列头点击按 `asc → desc → none` 循环；
- `shownStorages` 在排序非 `none` 时按本地化驱动名 `localeCompare`，同驱动内再按挂载路径排序；
- 列头带 `cursor:pointer`、`userSelect:none`，并用 `title` 提示「点击按驱动排序」，当前排序方向用 ▲/▼ 显示；
- 把原先动态 `For` 表头改成显式列，才能单独给「驱动」列挂点击事件。

### 3. 非表格布局按驱动分组

- 新增 `groupedStorages` memo：把筛选+排序后的存储按 `driver` 归组，组间按本地化名称排序；
- 网格布局由单层 `For` 改为「组 → 组内网格」两层结构，每组上方用 `Heading` + `Badge` 显示驱动名和数量。

### 4. 长文本溢出防护

[src/pages/manage/storages/Storage.tsx](../../src/pages/manage/storages/Storage.tsx) 的 `StorageListItem` 里，挂载路径、状态串、备注原先原样输出。用户给出的典型长串：

```
Post "https://user.mypikpak.net/v1/shield/captcha/init": proxyconnect tcp: dial tcp 127.0.0.1:10808: connectex: No connection could be made because the target machine actively refused it.
```

会把操作列顶出屏幕。处理：

- 给挂载路径/驱动/状态/备注单元格统一加 `maxWidth:260px` + `overflow:hidden` + `whiteSpace:nowrap` + `textOverflow:ellipsis`；
- 挂载路径与状态加 `title` 属性，鼠标悬停可看全文；
- 操作列设 `minWidth:180px` + `whiteSpace:nowrap`，保证按钮始终可见。

网格卡片原本已用 `wordBreak:break-all` + `overflowX:auto`，不会撑破，保持不变。

### 5. 多语言文案

- [src/lang/zh-CN/storages.json](../../src/lang/zh-CN/storages.json) / [en/storages.json](../../src/lang/en/storages.json)：新增 `sort_by_driver`（「点击按驱动排序」/ "Click to sort by driver"）；
- [src/lang/zh-CN/settings.json](../../src/lang/zh-CN/settings.json) / [en/settings.json](../../src/lang/en/settings.json)：新增后端本轮设置项的 key 与 tips —— `index_watch_enable`、`index_watch_enable-tips`、`index_watch_rules`、`index_watch_rules-tips`，含规则 JSON 示例与「需先启用数据库/Meilisearch 索引、bleve 不支持增量」的提示。
