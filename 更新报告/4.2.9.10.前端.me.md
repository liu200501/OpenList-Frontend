## 二、议题详情（前端）

### 1. 可配置独立代理（前端配置入口）

后端新增了两个通用/专属代理字段，前端补齐对应的多语言文案，让用户在存储编辑页就能配置：

- [src/lang/en/storages.json](../../src/lang/en/storages.json) / [zh-CN](../../src/lang/zh-CN/storages.json)：`download_proxy_url`、`download_proxy_url-tips`（"仅本存储下载文件使用的 HTTP(S) 代理，例如 http://127.0.0.1:10808；设置后该存储下载将走代理而非直链"）；
- [src/lang/en/drivers.json](../../src/lang/en/drivers.json) / [zh-CN](../../src/lang/zh-CN/drivers.json)：PikPak 与 PikPakShare 的 `api_proxy`、`api_proxy-tips`（用于列目录、登录、取链接等 API 请求）。

后端链路（通用 `download_proxy_url` 强制服务端代理、PikPak `api_proxy` 走独立 resty client）详见后端报告。

### 2. PikPak 分享免账号下载（仅调查，未修改）

结论：PikPak 分享链路不依赖账号，靠匿名 captcha token、分享密码派生的 pass code token、公开分享 API 即可工作。按要求未做任何修改。

### 3. 上传 `temp` 丢失

[src/pages/manage/tasks/Upload.tsx](../../src/pages/manage/tasks/Upload.tsx) 加上 `canRetry`，让 `/@manage/tasks/upload` 页面露出"重试 / 重试失败 / 重试选中"按钮。`canRetry` 是 `TypeTasks` 已有的可选 prop（见 [Tasks.tsx](../../src/pages/manage/tasks/Tasks.tsx) / [Task.tsx](../../src/pages/manage/tasks/Task.tsx)），本次只是此前没打开的前端开关。后端 `/task/upload/retry` 接口早已注册。

**已知限制**：机器重启场景若要真正"一键重试"，需要把任务元数据 + 完整服务端缓存一并持久化，当前未做。

### 4. 密文复制按钮 + 缓存并发选项

- 新增 [CipherCopyButton.tsx](../../src/pages/home/folder/CipherCopyButton.tsx)：仅当 `objStore.provider === "Crypt"` 且有 `encrypted_name` 时显示，阻止 mousedown/click/contextmenu 冒泡，避免触发选中或打开；标题与 aria-label 使用 `t("home.toolbar.copy_cipher_name")`；
- 接入 [ListItem.tsx](../../src/pages/home/folder/ListItem.tsx) 与 [GridItem.tsx](../../src/pages/home/folder/GridItem.tsx)，放在文件名容器内；
- [src/types/obj.ts](../../src/types/obj.ts) 增加 `encrypted_name?: string`；
- 多语言：[src/lang/en/home.json](../../src/lang/en/home.json) / [zh-CN](../../src/lang/zh-CN/home.json) 增加 `copy_cipher_name`（"复制密文"）；
- 缓存并发选项：后端注册 `image_preload_count`（PREVIEW 组数字设置），前端 [src/store/settings.ts](../../src/store/settings.ts) 增加健壮的 `getSettingNonNegativeInt(key, defaultV)`（非法/负数/缺省回退默认值）。

### 5. 压缩包内图片预览慢（前端部分）

| 根因                                                      | 前端修复                                                                                                                                                                                                                            |
| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 切一张图时预加载前后各 10 张，一次发出约 21 个 `/ae` 请求 | [image.tsx](../../src/pages/home/previews/image.tsx) 预加载张数改为可配置（默认 2、上限 100，读 `image_preload_count`）；预加载缓存从数组改为 `Map<url, HTMLImageElement>`，按 URL 复用已有 `Image`，窗口外的自动淘汰，避免无限增长 |

后端配套的解压落盘缓存 + singleflight、有界 Range、可缓存 `/ae` 响应详见后端报告。

多语言 [src/lang/en/settings.json](../../src/lang/en/settings.json) / [zh-CN](../../src/lang/zh-CN/settings.json) 增加 `image_preload_count`、`image_preload_count-tips`（"当前图片前后各预加载的图片数量（默认：2）"）。
